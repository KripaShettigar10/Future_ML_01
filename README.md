## 🚀 Project Overview

This project focuses on analyzing historical retail sales data and building a Machine Learning model to forecast future sales.

The main objective is to help businesses understand sales patterns, identify trends, and make better decisions through data analysis and predictive modeling.

## 🎯 Project Objectives

- Analyze historical retail sales data.
- Perform data cleaning and preprocessing.
- Explore sales trends and patterns.
- Build a Machine Learning model for sales forecasting.
- Evaluate model performance.
- Visualize sales insights using Power BI.

## ⚙️ Project Workflow

1. **Data Collection:** Obtained the Online Retail dataset.
2. **Data Preprocessing:** Cleaned the dataset and handled missing values.
3. **Exploratory Data Analysis:** Analyzed sales patterns and trends.
4. **Feature Preparation:** Prepared the data for forecasting.
5. **Model Building:** Implemented a Random Forest regression model.
6. **Model Evaluation:** Evaluated predictions using MAE, RMSE and R².
7. **Visualization:** Created an interactive Power BI dashboard.

## 📈 Model Performance

The Random Forest model was evaluated using the following metrics:

| Evaluation Metric | Result |
|---|---:|
| MAE | 14,151.37 |
| RMSE | 24,127.47 |
| R² Score | 0.4049 |

These metrics provide an overview of the model's forecasting performance on the test data.
